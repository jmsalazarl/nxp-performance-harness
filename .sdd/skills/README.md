# Skills Del Proyecto

Skills are reusable agent workflows or domain instructions that can be invoked when a task matches their purpose.

This project does not define custom skills yet. Candidate future skills:

- Generate a K6 config from a documented endpoint inventory.
- Review a K6 summary JSON and produce a performance assessment.
- Validar la completitud de `.sdd/specs` antes de implementar.

Each future skill should live in its own directory and include a `SKILL.md`.
